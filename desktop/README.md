# Сборка десктопной версии «ПВ-Система Текст»

Программа — обычное окно Windows, внутри которого работает интерфейс редактора.
Интернет для работы не нужен: все файлы лежат рядом с программой.

## Что установить на компьютере сборки

1. **Node.js LTS** — https://nodejs.org
2. **.NET 8 SDK** (именно SDK, не Runtime) — https://dotnet.microsoft.com/download/dotnet/8.0
3. **Inno Setup 6** (только если нужен установщик) — https://jrsoftware.org/isdl.php

## Как собрать

Скопируйте на компьютер **весь проект**, а не только папку `desktop`, и запустите:

```
desktop\csharp\build.bat
```

Готовая программа появится в `desktop\csharp\dist`. Запуск — `PVSTEKST.exe`.

### Варианты запуска

| Команда | Что делает |
| --- | --- |
| `build.bat` | Обычная сборка с защитой кода |
| `build.bat noobf` | Сборка без защиты кода (быстрее, если нет интернета) |
| `build.bat install` | Собрать и установить в `C:\PVSTEKST` с ярлыками |
| `build.bat installer` | Собрать один файл `PVSTEKST-Setup-1.0.0.exe` для раздачи пользователям |

## Версия программы

Указывается вручную в файле `desktop\APP_VERSION` — одна строка вида `1.0.0`.
Автоматического увеличения нет.

## Что получается на выходе

```
desktop\csharp\dist\
    PVSTEKST.exe        программа (один файл, .NET внутри)
    web\                интерфейс редактора
    pvstekst.ico        значок
    app_version.txt     версия
```

Установщик `PVSTEKST-Setup-<версия>.exe` кладёт всё это в `C:\PVSTEKST`,
создаёт ярлыки на рабочем столе и в меню «Пуск» и, если нужно,
доустанавливает компонент Microsoft Edge WebView2.

## Если что-то не собралось

Полный журнал сборки — `desktop\csharp\build.log`.
Ошибки самой программы при запуске пишутся в `error.log` рядом с `PVSTEKST.exe`.
